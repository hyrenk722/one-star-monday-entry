A one-star review of Monday, written as if Monday were a restaurant —
20 words, one line, plain text.

> Monday served my weekend cold, spilled my coffee on the to-do list, and the waiter shrugged: 'Kitchen's closed till Friday.'

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`) with no network access; two runs write
identical bytes.
